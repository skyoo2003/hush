# Support

Hush is maintained by one person in limited time, so support has fixed limits.

| Area | Scope |
| --- | --- |
| Platforms | The two latest major macOS versions, on Apple Silicon. |
| Versions | The latest release only. |
| Issues and pull requests | Triaged once a week. |
| Security reports | Private reporting only, as described in [SECURITY.md](SECURITY.md). |
| Questions | GitHub issues. There is no email or chat support. |
| Forks and self-built copies | Not supported. See [docs/building.md](docs/building.md) to build your own. |

Sponsoring pays for maintenance time. It does not buy priority support or extra features.
