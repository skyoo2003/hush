# Trademark policy

The code is GPL-3.0-or-later, and you may fork, modify, and redistribute it under that license, including selling it, as long as you publish your source. The license covers the code. It does not cover the project's name and icon.

## Rules

- A fork that is distributed to others must use a different name and a different icon. Change the constants in `src-tauri/src/brand.rs` and replace `src-tauri/icons/`.
- A fork must not suggest that it is the official Locite app or that this project endorses it.
- You may say that your fork is "based on Locite" and link to this repository.
- Unmodified builds of a tagged release, or builds that only fix packaging for a distribution, may keep the name.

Questions go to the lead maintainer listed in [GOVERNANCE.md](GOVERNANCE.md).

## Name history

The project was called Hush until 2026-11-23. It was renamed to Locite (local + cite) because "Hush" was already used by an open source privacy app for macOS ([oblador/hush](https://github.com/oblador/hush)). See ADR-012 in [docs/decisions.md](docs/decisions.md).

Open item: two unrelated apps use similar names (Locàite, a GPS tracker companion, and LocAite, a social app). A trademark search (KIPRIS, USPTO) for "Locite" has not been done yet.
