## 2026-11-22 (app scaffold)

Done
- Built the Tauri v2 + React/TS + Vite + pnpm app scaffold. `src-tauri/` has `brand.rs`, `error.rs`, `commands.rs`, and four modules (ingest, rag, storage, security), each with its own `error.rs`. `entitlement.rs` and `net.rs` hold only a doc comment.
- Added the `main` and `quick-search` windows. `quick-search` starts hidden and undecorated, and pressing Escape calls `hide_window`.
- Added 9 IPC commands as stubs. Only `hide_window` does anything; the rest return `not_implemented`.
- Split commands by window with per-window capabilities. A Rust test checks rejection and acceptance against the real capabilities. Details are in ADR-002.
- `build.rs` generates `src/brand.ts` from `brand.rs` and syncs the name, bundle ID, and window titles in `tauri.conf.json`. `scripts/check-brand.sh` catches hardcoded brand strings.
- Logs go to `~/Library/Logs/com.hush.app/`, rotated daily with 7 files kept. At startup the app logs only the window labels.
- Added CI (`.github/workflows/ci.yml`, macos-15). Switched from macos-14 because GitHub rejected that runner ("configuration not supported").
- Switched the project language to English and translated CLAUDE.md and docs/.
